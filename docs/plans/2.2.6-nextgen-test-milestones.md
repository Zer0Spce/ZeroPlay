## Milestones and pass/fail acceptance tests
**M1 / P0 – Updater 3.0 & Crash Recovery.** Atomic two-phase update with checksum, bounded retries, pointer validation, first-launch confirmation, rollback and single-process lock. PASS: corrupt/missing current pointer, checksum failure, child crash, timeout and interrupted download recover to stable state with preserved watch history and diagnostics. FAIL: startup crash or loss of library.

**M2 / P0 – Regression coverage.** Real pending-update launcher test + clean packaged startup, Windows zip icon/updater presence, all 4 Android release unit tests/lint/signature, cross-version migration. PASS: all CI gates green plus manual device testing. FAIL: any P0 crash/identity collision.

**M3 / P1 – Smart Playback Source 2.0.** Health-by-source and title; keep user override, retry/next, remember season/progress, cap fallback attempts, never treat reachable page as playable. PASS: simulated player error, timeout, Shaka 1002/1004, malformed manifest, offline/slow host and user override, no fallback loops.

**M4 / P1 – Top 10 Carousel 2.0.** Exactly approved 8 US streaming brands; TMDB/JustWatch US flatrate (no rental or invented provider); six-hour profile rotation, dedup and provider balancing; show up to 10 valid titles, honest empty state. PASS: wrong region, missing provider, future titles, low-vote, cache rollover, 429, exposure repeat handling.

**M5 / P1 – Provider Hub.** Movie and TV catalog for Netflix/Hulu/Disney+/HBO Max/Apple TV+/Paramount+/Peacock/YouTube TV with genre, new/popular and paging. PASS: no unavailable-provider substitution, US-region compliance, D-pad focus and pagination.

**M6 / P1 – Universal Search 2.0.** Debounced/movie-TV/genre/year/rating/provider filters, sorting, per-profile recent searches, cancellation and escape safety. PASS: empty/long/unicode terms, fast changes, cancellation, provider missing and rate limits.

**M7 / P1 – TV Tracker.** Watched episodes, season progress, next unwatched, resume and source-dependent play next. PASS: specials, missing episode, boundary transitions, 95% watched, per-profile isolation.

**M8 / P1 – Smart Watchlist 2.0.** Collections, migration, unwatched/watched, sort, verified provider hints. PASS: data preserved from v2.2.5.9, duplicate dedupe, renames/removals, profile switching and corrupt-state handling.

**M9 / P1 – Live & PPV Guide 2.0.** Today/Tomorrow/This Week, sports categories, Asia/Manila timezone, countdown and live/verified/reachable statuses. PASS: PHT midnight crossing, missing event times, ended events, unreachable sources, manual refresh; do not restore Live PPV favorites.

**M10 / P1 – Movie & TV Details 2.0.** Trailers, cast, related titles, subscription availability, season/episode and accessible playback/watchlist. PASS: no trailer, empty cast, metadata failure, focus-safe navigation and content escaping.

**M11 / P1 – Performance.** Dedup TMDB calls, bounded image cache/concurrency, cancellation and TTL, baseline device metrics. PASS: cold start, repeated browse, low memory, offline/rate-limited network, no stale-update overwrite. Measure before claiming improvements.
