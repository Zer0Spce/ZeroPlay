# ZeroPlay v2.2.6.4 — Carousel Provider Branding and Refresh Picks

## Android TV / Android
- Ships the **real** carousel used by the TV launcher: `PresentationMainActivity → CategoryMainActivity → ReleaseMainActivity.carousel()`, verified in user testing with a separate Android TV TEST2 APK.
- Visible, remote-focusable **Refresh picks** at the featured carousel's top-right.
- Streaming-provider wordmark appears under the film metadata and above the synopsis; image is from bundled compiled drawables, with US subscription-provider lookup when cached content lacks a brand.

- Remove temporary TEST2 marker, restore official package IDs, labels, and release signing. Production Android versionCode **69**, versionName **2.2.6.4**.
- All existing features, Continue Watching, playback and source selection are preserved.
