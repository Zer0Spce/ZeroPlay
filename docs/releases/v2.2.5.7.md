# ZeroPlay v2.2.5.7 — Smart Stream Status & Windows Updater Visibility

## Platforms
- Android Mobile — Full APK
- Android TV / Google TV — Full APK
- Android Mobile Lite — Lite APK
- Android TV Lite — Lite APK
- Windows x64 — portable ZIP with **ZeroPlayUpdater.exe**

## Live PPV status badges (Android and Windows)
- Clean live-channel titles (no “— Unverified” appended by ZeroStreams).
- **LIVE** in red and **VERIFIED** in green when ZeroStreams confirmed a live HLS manifest and recognizable live media data.
- **REACHABLE** in amber when the manifest can be read but live media data is not confirmed.
- **UNVERIFIED** in neutral gray when the check has insufficient evidence, times out, or a playlist has no status metadata.
- Status is informational, **not clickable**, not a playback guarantee, and may become stale between refreshes. The app never infers “LIVE” from an HTTP 200 alone.
- **Removed Add to Favorites from Live PPV**, only. Live TV favorites remain unchanged.
- The native Android Media3 Live PPV player remains the proven v2.2.5.6 implementation.
- The existing Windows Shaka/Electron streaming implementation is retained.

## Windows updater fixes
- Build and embed a fresh **ZeroPlayUpdater.exe** in the Windows portable ZIP; refuse release if helper is missing.
- The standalone updater stays visible after success or failure until **Close** is clicked.
- The helper displays installation progress, a live event log and a **Copy logs** button.
- Installer logs persist to `ZeroPlayUpdater.log` next to the root `ZeroPlay.exe`; failures are also recorded in `ZeroPlayUpdater-error.txt`.
- An update reports success only after the new ZeroPlay version confirms startup. An unsuccessful launch or automatic rollback is shown as a failure.
- Update discovery skips platform-only releases lacking Windows ZIP assets.

**Important for 2.2.5.5 users:** If the current Windows folder is missing ZeroPlayUpdater.exe, its older updater cannot self-install this repair. Download and extract the 2.2.5.7 Windows ZIP once into a fresh folder, preserving your user data. Future supported updates will have the helper packaged.

## ZeroStreams integration
ZeroStreams publishes `x-stream-status` in the M3U entry and a timestamped per-URL status in `status.json`. Playlist inclusion no longer depends on a probe succeeding, preserving access to temporarily failing candidates. The stream check performs bounded, public HLS reads only; it does not bypass DRM, credentials, or access restrictions.

## Build verification
Android: full and Lite, mobile and TV unit tests, package versionCode **62**, signed APK checks and lint. Windows: status tests, updater-helper source checks, self-contained .NET 8 helper compilation, Node tests, Electron packaging, actual ZIP helper-content inspection and packaged UI startup smoke check. Automated tests cannot guarantee playback for every external stream or validate updater GUI on all Windows installations.
