# ZeroPlay v2.2.5.4 — Android TV Controller Fix & Source Navigation

**Release date:** November 5, 2026  
**Platforms:** Android TV, Android mobile/tablet and Windows x64 portable  
**Base:** v2.2.5.3 — retains its Shaka 5.2.12 Live PPV playback and existing movie/series sources.

## What's new

### Android TV — Live PPV remote buttons now selectable

- Reworked the Live PPV controller to handle the **D-pad** directly, with left/right traversal between the player buttons.
- **OK / Enter / Center** activates the focused button explicitly; the remote Key Up event does not trigger duplicate actions.
- A visibly **highlighted, high-contrast focus state** shows which control will be activated.
- The first remote input after auto-hide **reveals controls without accidentally clicking**. Controls auto-hide again after 4.5 seconds of uninterrupted playback.
- Horizontal player controls scroll automatically to keep the focused button visible.
- **Up** focuses Back; **Down** returns to the playback toolbar. The channel picker keeps its own navigation.
- Play/Pause, Live, Retry, Channels, Audio, Subtitles, Fit, and Back keep their existing playback actions. No Shaka engine changes.

### Android TV — Choose navigation mode separately for each movie/series source

Open **Settings → Player → Navigation per movie / series source**.

- Global default: **Smart / Hybrid** (automatically chooses D-pad when a provider offers focusable controls, otherwise virtual mouse).
- For each provider, choose **Inherit global default**, **Smart / Hybrid**, **D-pad**, or **Virtual mouse**.
- Preferences are stored locally **per source**. A provider without an override inherits the global default.
- Changing providers or falling back to another provider automatically loads the navigation mode saved for that source.
- The player **Menu** navigation choice saves an override for the current movie/series provider, not for every provider.
- These settings affect **Android TV movie/series embed players only**. Live PPV has separate native controls, and Android mobile and Windows behavior is unchanged.

### Vidrock.to — Marked offline across source menus

- Renamed the provider to **Vidrock.to [Offline]** in Android TV, Android mobile, Windows and web source selectors.
- Preserved source ID `vidrock` and saved title-specific selections.
- Excluded Vidrock from **automatic best-source selection and fallback chains** so auto-recovery prefers other available providers.
- Kept the original manual entry and its documented `vidrock.to/movie/{id}` and `vidrock.to/tv/{id}/{season}/{episode}` URLs for testing if service returns.

**Note:** The VidRock provider's own playback availability is outside ZeroPlay's control. The label and automatic-source routing are fixed here; no claim is made that the remote VidRock service itself is repaired.

## Preserved features and boundaries

- The working **Shaka Player 5.2.12 Live PPV** playback engine remains unchanged.
- Native Live TV/IPTV, Live Sports, Android TV Home navigation, Windows player engine, Audio Booster 2.0, and other apps/tabs are unchanged.
- All source options from 2.2.5.3 remain: VidStuck, ZXCStream, Embedwave, VidSrc [Offline], Vidrock.to [Offline], VidNest, VidRift, VidFast, and VidAPI (plus RawCast where enabled).
- Stable backup branches and earlier release tags/assets are preserved.
