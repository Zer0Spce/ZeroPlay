# ZeroPlay 2.2.6.3 — Android TV Title Artwork & Refresh Picks Hotfix

## Fixes
- **Android TV carousel:** Align official TMDB movie-title artwork to the same left edge as the movie metadata and actions. Load title logos asynchronously using TMDB /images (English or language-neutral), with readable text fallback, and reject late results for previously selected films.
- **Background videos:** Android TV home-trailer autoplay carried movie logos embedded in the center of the video. Video pixels cannot be moved with Android view gravity. The TV home carousel now uses its static film backdrop and an app-managed left title logo to guarantee consistent placement. Homepage previews on other platforms remain unchanged.
- **Refresh picks:** TV-only remote-focusable button now lives in the **top-right corner** of the carousel, outside the narrow bottom action row.
- Preserve Continue Watching, streaming-provider badges, TV tabs, and playback behavior.

## Windows
Windows UI, playback, providers, layout and updater behavior are unchanged. Only the Windows build version/display and ZIP name change to 2.2.6.3 (internal Electron semver 2.2.6-3).

## Release
Android signed versionName 2.2.6.3, versionCode 68, same production package IDs. Windows x64 ZIP includes the current standalone updater. Four signed Android APKs and Windows ZIP with SHA256SUMS.txt. CI publishes only after both platform builds, tests and artifact-integrity checks pass. Physical TV verification is separate from automated checks.
