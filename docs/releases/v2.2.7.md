# ZeroPlay v2.2.7 — VidRift controls and new playback providers

Release date: 2026-11-23

## Changes
- VidRift: auto-hide recognized playback controls after 3.2 seconds of idle time during active playback; wake on mouse, touch, keyboard and focus events. Controls stay available when paused or a menu is open.
- NexStream: new optional movie and TV embed provider. The NexStream API credential is not included in the public source; deployments must configure `NEXSTREAM_API_KEY` and ensure the provider permits their domain.
- EmbedMaster: new movie and TV embed provider using documented `embedmaster.link` endpoints, onyx skin and direct player view.
- Retain VidStuck as the default source, with alternate providers selectable on supported platforms.
- Updated web landing page, source selectors, release links and updater-facing version information.

## Platforms
Android, Android TV / Google TV, Android Lite, Android TV Lite, Windows x64, Web.

## Notes
- Provider websites may change independently and third-party content availability is not guaranteed.
- Client-side credentials included in APKs or desktop binaries can be extracted. Use a properly protected server-side integration where applicable, and rotate any leaked credentials.
- The release build requires passing Android/Windows checks, signed APK validation, packaged Windows startup smoke tests and SHA-256 checksums before publication.
