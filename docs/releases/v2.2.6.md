# ZeroPlay 2.2.6 — Playback Reliability & Discovery

## Complete approved feature outline

1. **Windows Updater 3.0 & Crash Recovery.** Safer updates with bounded GitHub retries, checksum checks, recovery and rollback handling; visible standalone updater remains in Windows ZIP.
2. **Startup/Update Regression Tests.** Expanded Android/TV signatures, navigation, playback and startup checks, plus packaged Windows startup and update regression testing.
3. **Smart Playback Source 2.0.** Title-level health and preferred-source handling, capped fallback attempts, manual override respect, and avoidance of offline or quota-limited sources.
4. **Top 10 Streaming Carousel 2.0.** Up to ten verified US subscription movie picks from the eight explicitly approved streaming platforms, deduplication and provider balancing.
5. **Streaming Provider Hub.** Movies and TV browsing by Netflix, Hulu, Disney+, HBO Max, Apple TV+, Paramount+, Peacock and YouTube TV with provider-specific discovery.
6. **TV Series Tracker.** Watched episode and season progress, next-unwatched suggestions, and continue/resume helpers.
7. **Smart Watchlist 2.0.** Collections, existing saved data preservation, watched/unwatched filtering and improved watchlist controls.
8. **Movie & TV Details 2.0.** Trailers, cast, episode details, recommended titles and verified streaming-provider metadata where available.
9. **Performance Boost.** Deduplicated/coalesced TMDB requests, cache and reduced duplicate network work; actual performance depends on hardware and network.

## Requested final corrections

- Removed the large red “TOP 10 NEW STREAMING MOVIES · US” carousel overlay.
- Stream-provider logos are compact and displayed **above** featured movie titles on Windows and Android, avoiding cramped side-by-side typography.
- Android uses packaged streaming-provider logo assets with a verified TMDB image fallback.
- Android TV Modern UI suppresses nonessential “restored instantly”, “updating home” and “TMDB · 125 titles” diagnostics above the carousel.
- Android and Android TV filmography cards now respond to screen tap and remote OK/Select to open native movie/series details; the working Windows actor navigation is unchanged.
- **Excluded:** Universal Search 2.0 and Live TV & PPV Guide 2.0 have been removed. Original movie/series search, Live TV, Live PPV and Live Sports remain available.

## Packages

Four signed Android production flavors: mobile, TV, mobile Lite, TV Lite. Android versionName 2.2.6 and versionCode 65, with existing official package names. Portable Windows x64 ZIP contains ZeroPlay.exe and the standalone ZeroPlayUpdater.exe. SHA256SUMS.txt covers all five packages.

## Quality and compatibility

The release workflow publishes only after both Android and Windows jobs pass signature, lint, regression and packaged-startup checks. Device-specific hands-on testing is separate from CI. Streaming and TMDB metadata availability depend on third-party upstream services. For older Windows installations with a faulty updater, extract the new ZIP into a clean directory.
