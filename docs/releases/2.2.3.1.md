# ZeroPlay 2.2.3.1 — Android TV Lite Hotfix

Android TV Lite-only playback hotfix rebuilt from the proven v2.1.2 player implementation.

## What changed

- Restored the literal v2.1.2 Android TV player stack for Android TV Lite:
  - `BrowserPlayerActivity.java`
  - `TvMouse.java`
  - `PlayerAdScan.java`
  - `player-guard.js`
  - `tv-player-input.js`
- Those restored player files are kept equivalent to v2.1.2 except for changing the retired VidStuck host from `vidstuck.xyz` to `vidstuck.cc` wherever it appears.
- Current source routing remains in place so VidStuck resolves through the working `.cc` endpoint.
- Removed the previous 2.2.3.1 performance-tuning approach in favor of the actual v2.1.2 player baseline.

## Release scope

This release replaces only:

- `ZeroPlay-2.2.3.1-Android-TV-Lite.apk`
- `SHA256SUMS.txt`

No regular Android, Android Lite, regular Android TV, Windows, or web release is rebuilt or replaced.

The release remains an isolated GitHub prerelease so the stable 2.2.3 channel used by the other variants is untouched.
