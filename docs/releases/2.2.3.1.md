# ZeroPlay 2.2.3.1 — Android TV Lite Hotfix

Android TV Lite-only playback performance hotfix. No regular Android, Android TV, Android Lite, Windows, or web release is rebuilt or replaced.

## Fixed

- Reduced continuous player DOM/ad scanning pressure while VidStuck is playing.
- Increased the Lite TV player-guard mutation debounce and removed character-data observation from the hot path.
- Reduced the recurring full player scan from every 1.5 seconds to every 5 seconds for this Lite TV build.
- Reduced native QR/ad scan capture size from 1280px to 640px on Android TV Lite.
- Reduced QR/ad scan frequency from every 1 second during startup to every 2.5 seconds, then every 12 seconds after the initial player window.
- Restored the lighter 2.1-style virtual-mouse speed calculation for Lite TV so remote cursor movement avoids SharedPreferences work on every animation frame.
- VidStuck remains on the current `vidstuck.cc` domain. The retired `.xyz` domain is not restored.

## Release scope

This release contains only:

- `ZeroPlay-2.2.3.1-Android-TV-Lite.apk`
- `SHA256SUMS.txt`

It is intentionally published as an isolated GitHub prerelease so the existing universal 2.2.3 updater on other Android variants does not treat a TV Lite-only release as an update intended for them. Other 2.2.3 release assets remain untouched.
