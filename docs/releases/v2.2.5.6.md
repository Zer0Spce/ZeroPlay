# ZeroPlay v2.2.5.6 — Android Live PPV Native Playback Fix

**Android only:** Full Android, Android TV, Android Lite, and Android TV Lite.
**Windows unchanged:** No Windows source modifications, build, ZIP, or desktop update.
**ZeroStreams unchanged:** No changes to source discovery, playlist, schedules, or protected backups.

## Fix: Shaka 1002 on Android

The Live PPV catalogue used to launch Shaka inside Android WebView. Shaka HTTP_ERROR (1002) can occur when WebView's browser networking cannot complete a streaming request, including due to CORS restrictions. The Windows Electron player has network handling not available to Android WebView.

**v2.2.5.6 routes Live PPV and the existing Live TV/IPTV screen through ZeroPlay's native Media3/ExoPlayer activity.** Native HTTP HLS requests do not depend on WebView CORS. The existing native player uses playlist-specified User-Agent and Referer headers, media decoding, retries, event-safe alternate feeds, and diagnostic HTTP errors.

This does not guarantee playback of offline, restricted, expired, or unsupported streams. ZeroStreams currently publishes unverified HLS candidates; a published URL is not proof the stream is reachable or decodable. The actual provider response and device compatibility still determine playback.

## Preserved

- Android full and Lite home screens, movies, series, embedding, source selection, audio, subtitle controls, TV remote navigation, and other features remain in the existing codebase.
- Live TV/IPTV continues to use the same native player and separate playlist cache.
- The Shaka implementation remains available in the repository for investigation, but Live PPV no longer routes to it.
- Windows 2.2.5.5 files and prior GitHub releases remain untouched.
- The private TV flavor is not part of this public Android release.

## Verification and limitations

The release workflow runs native routing regression checks, Android unit tests, compiles and signs all four public Android flavors, verifies APK signatures, package IDs and versions, and generates SHA-256 checksums. Automated compilation cannot confirm playback on your specific device or network; verify a known-working live HLS feed in each installed Android variant after installing.

No Windows package is produced and no protected backup is modified.
