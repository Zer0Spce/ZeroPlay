# ZeroPlay 2.2.6.2 — Android TV Carousel & Continue Watching Fix

## Android and Android TV fixes
- Fix visibly centered movie/streaming-brand artwork: left-anchor the carousel artwork view and build each approved provider wordmark as an alpha-trimmed Android drawable, eliminating invisible transparent padding.
- Load logos for Netflix, Hulu, Disney+, HBO Max, Apple TV+, Paramount+, Peacock and YouTube TV from compiled Android resources, with asset and TMDB image fallbacks.
- Restore the TV **Continue Watching** row from saved items and watch-history snapshots even when a title is no longer present in rotating TMDB picks or older home-panel preferences disabled the shelf. Titles marked completed remain excluded; items with actual started playback are retained.
- Put a TV-only **↻ Refresh picks** button beside **Watch now** and **More info**, using the same button height and spacing. Refresh invalidates carousel caches and rotates the selection source.
- Preserve existing playback, watch history, TV remote focus, Modern UI, provider list and all nine feature areas from v2.2.6.
