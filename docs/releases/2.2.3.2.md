# ZeroPlay 2.2.3.2 — Android TV Lite Legacy Player Hotfix

Android TV Lite-only test release restoring the proven v2.1.2 player path as closely as possible, with the retired VidStuck domain changed from `vidstuck.xyz` to the current `vidstuck.cc` domain.

## Scope

- Android TV Lite only.
- Uses the v2.1.2 Android TV Lite player implementation as the baseline.
- Keeps the v2.1.2 player behavior and removes the newer 2.2.x player-layer changes from this build.
- Replaces only the obsolete VidStuck host/reference with `vidstuck.cc` where required for the current provider.
- Does not modify or rebuild regular Android, Android Lite, regular Android TV, Windows, or web releases.

This release is intentionally isolated as a prerelease so other ZeroPlay variants remain on the normal stable release channel.
